## Upgrade and limitations {#upgrade-and-limitations}

Before upgrading, back up the database, persistent data, and encryption keys as described in the [operations guide](./guide/operations.md). Do not delete persistent data to address an upgrade problem. Rehearse restoration in an isolated environment before enterprise use. This release does not provide cross-region disaster recovery or claim high-load testing or compatibility with every enterprise sign-in service.

Read the [operations guide](./guide/operations.md) and [known feature boundaries](./roadmap.md) before deployment.
